# Keybindings - Focus Follows Mouse + Yabai

## Sistema (Hammerspoon)

| Atalho | Ação |
|--------|------|
| Command + Control + L | Abaixar janela para o fundo |

---

## Yabai + SKHD (Window Manager)

### Foco de Janela

| Atalho | Ação |
|--------|------|
| Command + Seta Esquerda | Focar janela à esquerda |
| Command + Seta Direita | Focar janela à direita |
| Command + Seta Baixo | Focar janela abaixo |
| Command + Seta Cima | Focar janela acima |
| Command + B | Focar janela anterior |
| Command + 1 | Focar primeira janela |
| Command + 0 | Focar última janela |

### Navegar entre Displays

| Atalho | Ação |
|--------|------|
| Command + . | Display anterior |
| Command + , | Próximo display |

### Mover Janelas (Swap)

| Atalho | Ação |
|--------|------|
| Shift + Command + Seta Esquerda | Trocar com janela à esquerda |
| Shift + Command + Seta Direita | Trocar com janela à direita |
| Shift + Command + Seta Baixo | Trocar com janela abaixo |
| Shift + Command + Seta Cima | Trocar com janela acima |

### Redimensionar

| Atalho | Ação |
|--------|------|
| Control + Command + Seta Esquerda | Expandir para esquerda |
| Control + Command + Seta Direita | Expandir para direita |
| Control + Command + Seta Baixo | Expandir para baixo |
| Control + Command + Seta Cima | Expandir para cima |
| Control + Command + E | Equalizar tamanho das janelas |

### Ações de Janela

| Atalho | Ação |
|--------|------|
| Command + Caps Lock | Toggle float (livre/tiling) |
| Command + ] | Toggle fullscreen |
| Control + Command + P | Toggle sticky |
| Control + Command + C | Centralizar janela |
| Control + Command + S | Toggle split |
| Control + Command + Z | Zoom parent |
| Command + Q | Fechar janela |

### Layout

| Atalho | Ação |
|--------|------|
| Control + Shift + Command + B | Layout BSP (tiling automático) |
| Control + Shift + Command + F | Layout Float (janelas livres) |

### Spaces (Workspaces)

| Atalho | Ação |
|--------|------|
| Control + 1-9 | Ir para Space 1-9 |
| Shift + Control + 1-9 | Mover janela para Space |

### Mover Janela para Display

| Atalho | Ação |
|--------|------|
| Shift + Control + . | Display anterior |
| Shift + Control + , | Próximo display |

### Sistema

| Atalho | Ação |
|--------|------|
| Shift + Control + Option + R | Reiniciar Yabai |
| Shift + Control + Option + E | Recarregar SKHD |

---

## Legenda de Modificadores

| Símbolo | Nome |
|---------|------|
| Command | Tecla Command (⌘) |
| Option | Tecla Option / Alt |
| Control | Tecla Control |
| Shift | Tecla Shift |
